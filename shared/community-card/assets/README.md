# Community Card Assets

Place reusable player-card graphics here. Keep source assets modular rather than committing one pre-rendered image per player.

Recommended folders:

- `base/` — neutral card backgrounds and frames
- `tiers/` — Bronze/Silver/Gold/Author/Warrior/Champion tint/overlay treatments
- `rarity/` — rare/special overlays such as holographic/rainbow treatments
- `teams/` — franchise/team logos and card-specific team treatments
- `divisions/` — division stamps
- `seasons/` — season-of-entry stamps
- `staff/` — GM/AGM/Captain circular Franchise/Staff stamps
- `branding/` — MLETM/Community/TM marks used by the renderer
- `icons/` — small player-info table icons
- `portraits/` — generic/default portrait assets if used

Do not store font files here unless their redistribution license explicitly permits it. Renderers should document required fonts separately.
