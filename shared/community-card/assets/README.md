# Community Eligibility Card Assets

Place reusable eligibility-card graphics here. Keep source assets modular rather than committing one pre-rendered image per player.

Recommended folders:

- `teams/<team>/frame.*` — team-specific eligibility-card frame/background treatment
- `teams/<team>/logo.*` — franchise/team logo used on the card
- `divisions/` — division stamps
- `seasons/` — season-of-entry stamps
- `staff/` — GM/AGM/Captain circular Franchise/Staff stamps
- `branding/` — MLETM/Community/TM marks used by the renderer
- `icons/` — small player-info table icons
- `portraits/` — generic/default portrait assets if used

There is intentionally no rarity or tier asset family for the current eligibility-card V1. Those belong to the later collectible/career player-card system.

Do not store font files here unless their redistribution license explicitly permits it. Renderers should document required fonts separately.
